Character Designer & Illustrator

I'm a Senior in college and majoring in GIMM (Games, Interactive Media and Mobile Technologies) at Boise State University. GIMM is a program that teaches many aspects of game development and web dev. I have worked in game engines like Unity and Unreal. In web dev, I enjoy making visuals of the website and the layout. Being more a visual designer I prefer making the game graphics over the actual coding of things. Currently, I see myself as a 3D modeler, illustrator and texture maker. With my illustrations, I prefer making high render drawings, shown in my personal art. With 3D Modeling I can be a rigger and animater but not to the same extent. The program I work best in is Maya but would be looking to extend my knowledge to Blender which my knowledge is more limited in.
